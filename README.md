# Shadow's Archive

A portable static birthday archive for Shadow. The site uses only `index.html`, `style.css`, and `script.js`; open `index.html` directly or serve the folder with any static web server.

## Asset slots

Replace the clearly labeled placeholders under:

- `assets/images/denia/`
- `assets/images/archive/`
- `assets/images/contributions/`
- `assets/images/ocean/`
- `assets/audio/denia/`

Expected voice files are `birthday-jp.mp3` and `birthday-en.mp3`. Contribution and archive data is at the top of `script.js`.

## Release lock

The client-side experience unlocks at `2026-09-17T17:00:00Z`, equivalent to 18 September 2026 at midnight in Vietnam. This is an experience lock, not a security boundary.
